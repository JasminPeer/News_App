## ⚙️ Prerequisites & Setup

### Requirements
- Basic familiarity with `JavaScript`
- Git installed on your local machine

### Installation Steps
```bash
git clone https://github.com/JasminPeer/News_App.git
cd News_App
npm install
npm start
```
